# brainOS

William's persoonlijke Cowork skills.

## Skills

Elke skill draait alleen op expliciet verzoek (geen automatische triggers) en
levert een platte-tekst samenvatting in de chat — geen artifact. Bronnen:
Google Calendar, Gmail, Notion en Tana (Outliner).

- **[day-start](.claude/skills/day-start/SKILL.md)** — ochtendbriefing:
  agenda van vandaag, mail die aandacht vraagt, openstaande taken.
- **[weekly-roundup](.claude/skills/weekly-roundup/SKILL.md)** — terugblik op
  de afgelopen week (afgerond/openstaand) plus een korte vooruitblik.
- **[quarterly-review](.claude/skills/quarterly-review/SKILL.md)** —
  voortgang op doelen/OKR's en de belangrijkste resultaten van het kwartaal.
- **[yearly-review](.claude/skills/yearly-review/SKILL.md)** — jaaroverzicht:
  hoogtepunten, voortgang op jaardoelen, patronen en richting voor volgend
  jaar.
